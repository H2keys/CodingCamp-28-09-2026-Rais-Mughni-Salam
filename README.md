# Expense & Budget Visualizer

A mobile-friendly expense tracker built with HTML, CSS, Vanilla JavaScript, Local Storage, and Chart.js.

## Features

### Required MVP
- Input form: Item Name, Amount, Category
- Default categories: Food, Transport, Fun
- Form validation
- Scrollable transaction list
- Delete transaction
- Total Balance updates automatically
- Pie chart updates automatically by category
- Local Storage persistence

### Optional Challenges implemented
- Custom categories
- Sort transactions by date, amount, or category
- Dark/light mode toggle

## Folder Rules
- `css/style.css` is the only CSS file.
- `js/app.js` is the only JavaScript file.

## Run locally
Open `index.html` in a modern browser.

For GitHub Pages, push the project to a repository and enable Pages from the repository settings using the main branch and root folder.
